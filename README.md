LUXE — Premium E-Commerce Website

A modern and responsive premium e-commerce website built with HTML, CSS, and JavaScript. LUXE provides a clean, elegant shopping experience with product categories, shopping cart functionality, responsive design, and a premium fashion-focused interface.

🚀 Live Demo

"View Live Website" (https://parthonag07.github.io/luxe-premium-ecommerce/)

📌 Features

- ✨ Modern premium UI design
- 📱 Fully responsive layout
- 🛍️ Product browsing and shopping experience
- 🛒 Shopping cart functionality
- ❤️ Wishlist interface
- 👤 Account interface
- 🔎 Product/category navigation
- 👕 Clothing, accessories, and footwear categories
- 📧 Newsletter subscription section
- 🎨 Clean typography and elegant design
- ⚡ Fast and lightweight frontend
- 🌐 GitHub Pages deployment

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, responsive design and animations
- JavaScript — Interactive functionality
- Git & GitHub — Version control and deployment
- GitHub Pages — Live hosting

1. Clone the repository

2. Open the project

Open the project folder in VS Code.

3. Run the website
